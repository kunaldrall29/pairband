
# R01 — Resume a partially completed stage

Read repository instructions, docs/MASTER_CONTEXT.md, docs/build-session.json, docs/BUILD_STATUS.md and the active stage. Inspect current branch/diff and evidence before changing anything. Identify completed work, failed checks, uncommitted user changes and remaining acceptance criteria. Do not restart the project or replace existing work with a new scaffold.

Reproduce only the concrete unresolved failure or gap, choose the smallest coherent fix and run meaningful affected checks. Keep product units/lifecycle/authority unchanged unless a recorded ADR is required. If a provider credential is absent, finish safe local preparation and name the blocked integration; do not fabricate a live response. Continue the original stage until accepted or concretely blocked. Update state/evidence and report exact next action. Do not rerun already authorized external transactions to reconstruct a missing local note; first reconcile hashes and state.
